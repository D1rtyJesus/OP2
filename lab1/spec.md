Main goal: створити логічну ER-модель для персонажів MGS...

Сутності та атрибути:

    Character (Персонаж): id (PK, string), name (string), role_type (string: протагоніст, герой,антогоніст, антигерой, друг, напарник, наставник, босс), final_status (string: живий, мертвий, невідомо(або більше уточнення)).

    Snake (Снейк): id (PK, string), codename (string: Solid, Naked, Venom, Liquid, Solidus), is_clone (boolean).

    Game (Гра): id (PK, string), title (string), release_year (number), chron_order (number).

Зв'язки:

    Character з'являється у Game (багато-до-багатьох).

    Snake є головним протагоністом у Game (багато-до-багатьох).

    Character взаємодіє зі Snake (багато-до-багатьох).


    Побудувати ER-модель декларативно; згенерувати erDiagram. Обов'язково вказати всі сутності, атрибути, первинні (PK) та зовнішні (FK) ідентифікатори, а також кардинальності зв'язків. Без сполучних таблиць (напр. user_roles): чистий «багато-до-багатьох» — це зв'язок між сутностями; асоціативна сутність — лише коли зв'язок несе власні атрибути.
